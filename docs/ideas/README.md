# Ideas and research

A place for ideas and research that are not ready to be an ADR. Write a note
here when you do not want to lose something, and you are not yet sure it
becomes a decision.

## Rules

- **Not binding.** A note records what was learned and what might be done.
  Contracts, tests, and agents never rely on it. A decision is an ADR in
  `docs/decisions/`.
- **One topic per file.** Name the file for its topic, with no number, as for
  `architecture/`, `reference/`, and `stack/`.
- **Each note starts with a status line:** `idea`, `researched`, `promoted to ADR NNNN`, or `dropped`, and the date it was last changed.
- **Keep the facts checkable.** Link sources, and say what was not verified.
- **Promote, do not move.** When a note becomes an ADR, link the ADR from the
  note and leave the note as the record of what was found.
- **Same content rules as the rest of the repo.** See `CONTRIBUTING.md`.
