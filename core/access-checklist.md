# Access checklist

Track what you need, who grants it, and when you asked. Record where access is granted, never the credentials.

| Item | Needed for | Who grants it | Requested | Granted |
| --- | --- | --- | --- | --- |
| Email and calendar | Communication | `<role>` | | |
| Chat | Daily contact with the team | `<role>` | | |
| Video meeting account | Meetings | `<role>` | | |
| Single sign-on / identity | Gateway to other tools | `<role>` | | |
| VPN or network access | Internal systems | `<role>` | | |
| Document and wiki space | Reading and writing docs | `<role>` | | |
| Work tracker | Seeing and updating tasks | `<role>` | | |
| Physical access or badge | On-site work | `<role>` | | |
| Hardware | Your working device | `<role>` | | |
| Discipline specific access | See your variant | `<role>` | | |

## Rules

- Ask for least access that lets you work. Add more when you need it.
- Use your own named account. Never share one.
- Record access you no longer need and request removal when the engagement ends.
- Escalate a blocked request after one working day.
