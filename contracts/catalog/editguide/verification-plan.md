## Named remaining evidence and fixture gaps

Native ACL/xattrs/file flags and inherited-private-temp refusal need actual
platform-specific setups, including permission-inspection failures. Never
strip ambient controls or assume absent metadata after an error. Parent lock
semantics must be proven on each supported filesystem/platform; named skipped
preconditions are gaps, not passing support. Add parent-chain replacement,
post-consent native control changes, temp short-write/close/cleanup faults and
after-publication cleanup failures. Concurrent command races need bounded joins
and retained exclusively owned sandbox on uncooperative workers; do not tear
down t.TempDir while native workers may still use it. Hostile CAS remains outside
the claimed model, not a test skip disguised as safety.

Add both sides of every numeric bound: argv/path/source/native metadata, staged
operation/Add/binding/list counts, total framed input, encoded bytes and quoted
review expansion. Add count canonicalization retries, all value forms, optional
pointer/fidelity edge cases, compound warning order, all-safe quoting controls,
actual secret projection, input n+EOF/n+error/no-progress, borrowed stream closure
and unchanged/cancel report failures. Current fixtures are not exhaustive proof.

Binary routing data covers normal creator→editor support and personal byte
preservation on cancel/refusal/success/no-op. Whole-binary stale mutation during
review needs a separately approved streaming runner/data capability; current
YAML cannot express it. Native public Run stale tests are not mislabeled as
whole-binary proof. Read-exclusion/native observer and dependency inspection
must verify no adjacent personal reads or unexpected calls, not merely that
adjacent files were left unchanged.

After source freezes run native/race checks, mutation, an independently authored
