# Start from the invitation ZIP

An invitation contains the organization plan, onboarder-owned preparation,
an identity-only newcomer record seed and first-steps.md. Read its first-steps
document and contact the named onboarding owner if anything is missing. Use
only the supported standalone tool supplied through your organization's
approved route; this catalog invents no download address or installation command.

Before any future import, the account must be confirmed as yours and proposed
destinations reviewed. A ZIP entry name is not permission to extract over local
files. If the account is wrong or you already have newer work, stop and ask the
owner. Keep existing plan, preparation and record files rather than replacing
them from an older invitation. Anyone who can read stored records can read
their answers and notes; keep credentials and unnecessary personal data out.

The supported invite export operation creates a new archive for an onboarder
to deliver through an approved external channel. It does not send the package,
import it, confirm identity or record first use. Confirmed invitation import
and record-backed startup remain staged work. The existing start command is
a legacy organization-plan flow, not an invitation-ZIP importer. Do not pass
the archive to it expecting this planned behavior.

Use the actual rendered first-steps help and selected business support route
for bootstrap work before company access exists. This static catalog entry
does not render a personal invitation, assert contact availability or duplicate
the first-steps assembler's account-specific guide. Reading a preview or this
entry records no start, accepts no default and verifies no activity.
