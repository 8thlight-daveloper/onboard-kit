# Start from the invitation ZIP

An invitation contains the organization plan, onboarder-owned preparation,
an identity-only newcomer record seed and first-steps.md. Read its first-steps
document and contact the named onboarding owner if anything is missing. Use
only the supported standalone tool supplied through your organization's
approved route; this catalog invents no download address or installation command.

Open the invitation with an explicitly selected existing record root:

```text
onboard-kit start --invitation FILE --root DIR [--home DIR]
```

Confirm the displayed account is yours, then review every proposed destination
and action. Identity confirmation alone writes nothing. Only choose begin after
the complete review if you want the proposed opening. Cancel before begin leaves
your files unchanged. A ZIP entry name is not permission to extract over local
files. If the account or destinations are wrong, stop and ask the owner.

Existing matching preparation is retained. Existing records are reconciled with
changes shown in review; their outcomes, notes and first-use history are preserved.
A different local plan needs a separate explicit choice before replacement.
No date decides which copy is newer. Anyone who can read stored records can read
their answers and notes. Private recovery copies may temporarily exist in the
state home and selected artifact parents;
keep credentials and unnecessary personal data out.

After begin, the tool opens a read-only record-backed session with instructions,
questions, waiting work and available support. It saves no answers or outcomes
and executes no commands or checks. Only a confirmed begin creating a genuinely
new local record records firstOpenedAt. Existing events are preserved; an existing
record without an event stays unknown. This is tool use, not an employment start
date or completion of an activity.

After leaving that view, the separate session edit command can review and save
one personal answer, follow-plan choice or outcome in the registered context.
Use the explicit absolute root, state home and registered session key described
in Resume onboarding. Opening an invitation does not consent to those changes.

If opening is interrupted, retain its recovery data and transaction token. Follow
the interrupted-opening recovery instructions in Resume onboarding; recovery
does not need the original ZIP. An invitation export alone sends nothing,
confirms no identity and records no first use. The separate start --org-plan
and walk routes retain their legacy plan-file behavior.

Use the actual rendered first-steps help and selected business support route
for bootstrap work before company access exists. This static catalog entry
does not render a personal invitation, assert contact availability or duplicate
the first-steps assembler's account-specific guide. Reading a preview or this
entry records no start, accepts no default and verifies no activity.
