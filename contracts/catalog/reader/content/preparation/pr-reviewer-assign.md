# Assign a reviewer

Identify an appropriate available reviewer and the normal review request route
for a first real change. Keep shared branching and review rules in the plan.
Use pr-post for the personal arrangement and link an actual declared posting
section instance. There is no pr-reviewer-assign arrangement kind.

An arranged item requires a known owner, at least one known helper contact
and a nonsecret change or opportunity reference. The helper is the assigned
reviewer, not automatically the owner. Use a stable unique id; an optional
real targetDate coordinates availability. Pending, requested and deferred can
retain missing assignments visibly, but unknown supplied contacts are invalid.

Discuss expected context, checks and how to handle reviewer absence. A named
reviewer is not a review request sent, approval granted or change delivered.
Do not invent a reviewer from a guessed variable name or write a personal
arrangement into shared answers. Preparation status changes no newcomer record.
